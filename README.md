# Calculadora Científica

Calculadora científica desenvolvida com HTML, CSS e JavaScript puro.

## Funcionalidades

- Operações matemáticas básicas: adição, subtração, multiplicação e divisão
- Potenciação e fatorial
- Raiz quadrada
- Funções trigonométricas: seno, cosseno e tangente
- Funções trigonométricas inversas
- Logaritmo na base 10 e logaritmo natural
- Constantes matemáticas π e e
- Alternância entre graus (DEG) e radianos (RAD)
- Suporte ao teclado

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou executar um servidor.
